CORE ARCHITECTURE · ZERO HALLUCINATION

Claim-Anchored Provenance Pipeline

Unlike naive RAG systems that summarize unstructured case narratives directly, CyberCase enforces strict deterministic evidence provenance before generating findings:

  • Decomposition: case_native_analysis.py decomposes narratives and OCR transcripts into atomic claims and exact quotes.
  • Character-Span Binding: case_native_binding.py validates that each quote resolves to a deterministic character offset and page in the immutable CaseEvidenceSnapshot.
  • Budget Selection: case_native_selection.py enforces deterministic coverage and token caps, recording omitted claims.
  • Grounded Output: Assistant findings reference only admitted claim IDs—no citation without an exact evidence quote.

ASYNC EXECUTION · INTERACTIVE GATING

Worker Leasing & Clarification Gating

Long-running analysis runs execute asynchronously via a background lease engine with proactive information gap detection:

  • Database Leasing: case_run_claim.py atomically acquires queued runs via PostgreSQL row-level locks.
  • Gap Evaluation: followup/decision.py inspects extracted case elements (perpetrator, damages, timeline holes).
  • Selective Pausing: If critical facts are absent, the run completes as awaiting_followup, persisting a focused clarification question with selected_gap_detail.
  • Chat Isolation: analysis_result messages remain withheld during follow-up; only resolved, fully verified findings publish to the overview.

EXTERNAL ENRICHMENT · TECHNICAL APPENDIX

MITRE ATT&CK & Report Generation

External threat intelligence is strictly isolated from incident case evidence to preserve legal admissibility and factual guarantees:

  • Conditional Trigger: case_mitre_augmentation.py queries rag_service only when confirmed cyber threat indicators appear.
  • Hybrid Graph Search: Vector similarity in Qdrant (BGE-M3 1024-dim) combined with 2-hop graph expansion in Neo4j (STIX 2.1).
  • Source-Role Isolation: ATT&CK techniques are displayed strictly in a technical appendix, never as incident evidence.
  • Export Engine: case_report_generation.py compiles findings, citations, and audit trails into Markdown and publication-grade PDF.
